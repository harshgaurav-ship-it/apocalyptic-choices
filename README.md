# Mumbai: Afterlight — Chapter 1 Build 0.1

This is the first production build of **Mumbai: Afterlight**, an original offline cinematic choice game set in Mumbai.

## What is playable

**Episode 1: The Last Train — Act I** is playable from Platform 3 through the Dadar Service Gate. It establishes the core group, consequence system, and the first-night state that Act II will continue from.

The build includes:

- 30-second timed choices with a no-timer accessibility setting
- Original CSS characters and cinematic environments
- Environmental investigation, item selection, and relationship choices
- Persistent Kavya, Kabir, Zoya, and Raghav trust state
- Local checkpoint saving and a first-night consequence recap

## Play

Open `index.html` in a current desktop browser. No installation, account, server, or internet connection is required.

## Controls

| Action | Control |
|---|---|
| Advance or reveal dialogue | Click dialogue, Space, or Enter |
| Make a timed choice | Click an option, or press 1 / 2 / 3 |
| Inspect Ticket Hall clues | Click highlighted objects, or press 1 / 2 / 3 |
| Resume a saved game | Continue Checkpoint on the episode menu |
| Disable timers | OPTIONS → Choice timer |

## Project rules

This build remains ₹0: it uses only HTML, CSS, and local JavaScript. It contains no downloaded art, audio, SDKs, analytics, subscriptions, or external services. The story, characters, and dialogue are original IP.

## Production path

1. **Episode 1 — The Last Train:** Act I is playable in this build; Act II expands the aftermath of the Service Gate.
2. **Episode 2 — No Way Home:** survivor-group tensions and the first betrayal.
3. **Episode 3 — The Other Side:** the safe settlement and its hidden cost.
4. **Episode 4 — Mumbai:** monsoon crossing toward the evacuation zone.
5. **Episode 5 — Afterlight:** consequence-driven conclusion.

See `STORY_BIBLE.md` for the locked character and chapter foundations.
See `CHARACTER_AUDIO_BIBLE.md` for the visual design, voice direction, and soundscape plan.
